## Which steps of a project could be handed to an agent

An agent is useful in the brainstorming phase, where it can suggest ideas, but every suggestion must be verified against the data or a source, and I will never rely on its output blindly. Routine work can be handed over to it, for example, drafting documentation, writing download scripts, plotting code or docstrings. However, the decisions behind this work must remain human: which sources and licences to use, how to treat missing values, what counts as a "country" or an "EU member", which hypotheses to test or how to interpret and visualise the results.
